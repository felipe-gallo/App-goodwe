# Instruções do projeto Goodwe

- Trabalhe somente dentro deste repositório e preserve alterações não relacionadas.
- O front-end deve permanecer em TypeScript e React Native, sem Expo, Expo Router ou EAS.
- Não implemente backend, autenticação, QR Code, pagamento ou recarga reais nesta etapa.
- Todos os dados são fictícios e locais; nunca adicione credenciais ou dados bancários reais.
- Não use comandos destrutivos, `git reset --hard` ou force push.
- Faça alterações pequenas, validáveis e commits apenas por etapa funcional.
- Envie commits somente para a branch de funcionalidade, nunca para `main`.
- Execute typecheck, lint, testes e build Android aplicáveis e documente limitações.
- Não declare iOS nativo testado sem macOS e Xcode.
